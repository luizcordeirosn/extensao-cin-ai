# Formação em Inteligência Artificial para Automação Industrial – Fundamentos e Aplicações

Este repositório contém as soluções e os projetos desenvolvidos durante o curso de extensão **"Formação em Inteligência Artificial para Automação Industrial – Fundamentos e Aplicações"**, oferecido pelo CIn-UFPE.

---

## 🚀 Sobre o Curso

O programa de extensão tem como objetivo capacitar profissionais para aplicar conceitos fundamentais e avançados de Inteligência Artificial e Machine Learning na resolução de problemas práticos no contexto da automação industrial. Ao longo do curso, foram abordados diversos desafios que cobrem desde a representação de dados até a implementação de modelos de *deep learning* e o uso de LLMs.

---

## 📁 Estrutura do Repositório

O repositório está organizado por desafios, cada um focado em uma área específica da Inteligência Artificial.

| Arquivo/Desafio | Tópico Abordado | Ferramentas/Linguagem |

| `Desafio_08_Expanding.ipynb` | Aplicação do princípio de Expansão para geração de textos. | Jupyter Notebook |

## 🚀 Como Utilizar

1.  Clone este repositório para a sua máquina local:
    ```bash
    git clone https://github.com/luizcordeirosn/extensao-cin-ai.git
    ```
2.  Navegue até a pasta do desafio de seu interesse.
3.  Para os arquivos `.ipynb`, abra-os usando o Jupyter Notebook ou Google Colab.
4.  Para os arquivos `.ows`, utilize o software [Orange Data Mining](https://orangedatamining.com/) para abri-los.
5.  Certifique-se de instalar as dependências listadas nos notebooks antes da execução.
